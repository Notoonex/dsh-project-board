# 域包：life / research

## 节点候选库

| 编号 | 名称 | 范围 |
|---|---|---|
| 00 | 治理 | 目标 / 边界 / 复盘节奏 |
| 10 | 基础 | 工具 / 数据 / 环境 / 记录方式 |
| 20–59 | 生活域 / 工作流 | 按真实领域拆（饮食 / 训练 / 求职 / 学习…） |
| 60–69 | 产出 | 文章 / 作品 / 申请材料 |
| 90 | 归档 | 已完成 / 放弃 |

## 推导

- 个人项目没有现成 IA，靠目标 + 日常动作推导。
- 节点 = 一个能独立判断「这块做得怎么样」的领域 / 工作流。
- 阶段 / 里程碑是属性，不是节点。
- 记录密度低时宁少勿多（3–5 个）。

## 注意

- 不要把「每天」做成节点。
- 不要把情绪 / 状态做成节点。
- 项目结束后整体进 `90`，不删。
