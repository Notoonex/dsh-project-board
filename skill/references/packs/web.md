# 域包：web-app / landing / content

## 节点候选库

| 编号 | 名称 | 范围 | 适用条件 |
|---|---|---|---|
| 00 | 治理 | 定位 / 边界 / 文档规范 / 阶段归档 | 必有 |
| 10 | 全局与架构 | 技术栈 / 部署 / 数据 / 安全 / 埋点 / SEO | 必有 |
| 20 | 首页 | 首屏 / 导航 / 对外第一屏 | 有对外页面 |
| 30 | 核心流程 | 主业务动作 / 状态机 | 有主流程 |
| 40 | 账户 | 注册 / 登录 / 会话 / 找回 / OAuth | 有自建账户 |
| 50 | 个人中心 | 资料 / 订单 / 设置 / 历史 | 登录后有自助页 |
| 60 | 内容与素材 | 内容模型 / 素材 / 校对 / 版权 | 有内容库 |
| 70 | 商业化 | 定价 / 支付 / 权益 / 广告 | 有付费 |
| 80 | 管理后台 | 审核 / 配置 / 数据 / 治理 | 有运营端 |
| 90 | 归档 | 已完成阶段 / 废弃节点 | 必有 |

## 账户 / 个人中心判定

| 产品形态 | 40 账户 | 50 个人中心 |
|---|---|---|
| 无账户 | ✗ | ✗ |
| 只有第三方一键登录 | ✗（并入 30） | ✗ |
| 自建注册 / 登录 / 找回 | ✓ | ✗ |
| 登录后有资料 / 订单 / 设置 | ✓ | ✓ |
| 有运营端 | ✓ | ✓（+ 80） |

口径：**账户是「进门」，个人中心是「进门之后能自己管什么」。**

## 推导

1. 读路由 / 页面 / 菜单，列「用户可达面」。
2. 按用户旅程排序：进入 → 认证 → 主流程 → 自助 → 付费 → 内容。
3. 每组问三问；成立才立节点。
4. 横切能力（设计系统 / 部署 / 安全 / SEO）收进 `10`，不单开节点。

## 注意

- 平台（Web / 小程序 / App）默认是属性；独立发布 + 独立验收才立节点。
- 语言 / 地区默认是属性；独立运营才立节点。
- 同名节点在不同项目里边界可以不同，必须写 `> 范围：`。
- 页面是条目，不是节点；100 个页面也还是 8 个领域。
